### ⚡ [AetherDB](https://github.com/yashwantraj147-eng/AetherDB)
**Hybrid Key-Value & Columnar Storage Engine Prototype**

Custom storage engine written in Java exploring the unified convergence between operational key-value stores and analytical column engines.

- 🗄️ **LSM-Tree Write Pipeline**: Append-only Write-Ahead Log (WAL) with CRC32 frame verification, memory skip-list tables, and multi-level SSTables.
- 📊 **Vectorized Columnar Tier**: Adaptive Run-Length (RLE) and Dictionary compression with Min-Max Zone-Map block skipping for fast analytical scans.
- 🧭 **Raft & Sharding Prototype**: In-memory Raft state machine simulation with 64 consistent-hashing virtual nodes (`vnodes`).

```
Stack: Java (21–26) • Virtual Threads • Zero External Dependencies • JUnit 5
```
